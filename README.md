# Group-Project-Integrated-Information-Technology
Backend development for an E-Commerce web application using Spring Boot + MySQL, providing RESTful APIs with secure JWT authentication, password hashing using Argon2, product image upload & management, role-based authorization, and data validation. Deployed via Docker Compose & Nginx with HTTPS (TLS).
